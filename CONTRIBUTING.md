# Contributing

This repository presents a personal portfolio and project work.

## Guidelines

- Keep project descriptions accurate and consistent with the actual repositories.
- Preserve responsive behavior and accessibility when editing UI components.
- Do not add personal data, credentials, or deployment secrets to source control.
- Run the production build before submitting frontend changes.

## Pull requests

Describe the page or component changed, the user-facing effect, and the validation performed. Keep visual and content changes focused.
