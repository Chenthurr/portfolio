## Run Locally

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/Chenthurr/portfolio.git
cd portfolio
npm install
```

### Development

```bash
npm run dev
```

The development server will provide a local URL in the terminal.

### Production Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
